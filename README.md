# HEIPNG

A simple Electron desktop app for bulk converting HEIC/HEIF images to JPG or PNG.

## Features

- Bulk conversion via drag & drop or file picker
- JPG (with quality slider) or PNG output
- Choose any output folder
- Aspect ratio preserved — no resizing or cropping
- Clean, dark, Discord-inspired UI

## Development

```bash
npm install
npm start
```

## Build installer

```bash
npm run dist
```

Output: `dist/HEIPNG Setup <version>.exe`
